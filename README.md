## Overview
This repository serves as a professional portfolio documenting the completion of the **Google Data Analytics Professional Certificate** offered through Coursera.

This program covers the complete data analysis process—Ask, Prepare, Process, Analyze, Share, and Act—using industry-standard tools to solve real-world business problems through data-driven insights.

## Technical Proficiencies
- **Data Lifecycle:** Managing the end-to-end process from problem definition to stakeholder communication.
- **Data Wrangling:** Cleaning, filtering, and transforming datasets using spreadsheets, SQL, and R.
- **Analysis:** Performing descriptive, diagnostic, and predictive analysis to identify trends and patterns.
- **Visualization:** Creating impactful dashboards and reports to communicate key findings to non-technical stakeholders.
- **Programming:** Utilizing R for statistical analysis and automated data processing.

## Course Curriculum & Projects

| Module | Focus Area | Key Deliverables |
| --- | --- | --- |
| 01 | Foundations | Data analyst roles, ethics, and the PACE/data lifecycle |
| 02 | Ask | Problem framing and stakeholder requirements |
| 03 | Prepare | Data collection, bias identification, and storage |
| 04 | Process | Data cleaning and integrity validation |
| 05 | Analyze | Exploratory analysis using SQL and spreadsheets |
| 06 | Share | Visualization best practices and storytelling |
| 07 | Act | Data-driven recommendations and presentations |
| 08 | Capstone | End-to-end analysis of a real-world dataset |
